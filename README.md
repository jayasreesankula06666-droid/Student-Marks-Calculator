# Student Marks Calculator 🎓

A beginner-friendly student project built with HTML, CSS, and JavaScript.

## Features
- Enter a student's name.
- Choose between 3 and 8 subjects.
- Enter marks from 0 to 100 for each subject.
- Automatically calculate total marks and percentage.
- Display a grade and pass/fail status.
- Responsive design for mobile and desktop.
- Reset the form to calculate another student's result.

## Grade rules
- A+: 90–100%
- A: 80–89.99%
- B: 70–79.99%
- C: 60–69.99%
- D: 50–59.99%
- E: 35–49.99%
- F: Below 35%, or if any subject mark is below 35

**Passing rule:** A student must score at least 35 in every subject.

> These are example grading rules. Change them in `script.js` if your school or college uses a different system.

## Run locally
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.

No installation or server is required.

## Publish with GitHub Pages
1. Upload all project files to the root of your GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages** from the sidebar.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. The website URL will appear in the Pages section.
